## Selected upstream contributions

- **AWS: aws-lc-rs [#1292](https://github.com/aws/aws-lc-rs/pull/1292) + aws-lc [#3780](https://github.com/aws/aws-lc/pull/3780).** aws-lc-sys did not build for QNX 8.0, blocking rustls, hyper-rustls and reqwest there. Fixed the cc_builder for `nto` targets and the aarch64 QNX link failure (`OPENSSL_cpuid_setup`). Found while building the top 500 crates for QNX ([qnx-crate-atlas](https://github.com/Mattbusel/qnx-crate-atlas)).
- **OWASP CycloneDX: cyclonedx-rust-cargo [#898](https://github.com/CycloneDX/cyclonedx-rust-cargo/pull/898).** cargo-cyclonedx wrote the `metadata.tools` array deprecated in CycloneDX 1.5 for every spec version (including SBOMs maturin and uv embed in wheels). Now writes the object form for 1.5 to 1.7. Closes #825.
- **MAVLink / Dronecode: rust-mavlink [#576](https://github.com/mavlink/rust-mavlink/pull/576), [#577](https://github.com/mavlink/rust-mavlink/pull/577).** The code generator defaulted bitmask enums to their first flag, so a default `GIMBAL_DEVICE_INFORMATION` claimed a retract capability. Now default to empty, with a regression test (fixes #557). Plus a fix for the CI job that failed on every PR after Cargo 1.100.
- **PX4: px4-ulog-rs [#11](https://github.com/PX4/px4-ulog-rs/pull/11), [#12](https://github.com/PX4/px4-ulog-rs/pull/12).** Opt-in `serde` feature so flight-review-rs writes log completeness straight to `metadata.json` (closes #9); clippy fix.
- **Moov Watchman (sanctions screening): [#1019](https://github.com/moov-io/watchman/pull/1019).** The OpenSanctions Senzing loader ignored `NAME_ORG`, so all 207 DoD 1260H entities and 13 of 13 FCC Covered List entries loaded with empty names, and aliases were dropped. Fixed both; docs now list my restricted-parties feed ([#1025](https://github.com/moov-io/watchman/pull/1025), [#1026](https://github.com/moov-io/watchman/pull/1026)).
- **daily_stock_analysis (73.3K stars): [#2537](https://github.com/ZhuLinsen/daily_stock_analysis/pull/2537).** Screening, alerts and reports computed RSI three different ways (one 200-bar series read 26.36 oversold in the screener, 50.19 neutral in the report). Unified on one Wilder RSI from my fin-primitives library (now in its requirements.txt).
- **PraisonAI (9.3K stars): [#6433](https://github.com/MervinPraison/PraisonAI/pull/6433).** Agent cost tracking billed every model newer than gpt-4o / Claude 3.x at a $1/$3 default, so `total_cost` and `max_budget` undercounted (a 100K-in / 5K-out gpt-5.5 call: $0.115 instead of $0.65). Now priced at list rates, including cache reads and writes.
