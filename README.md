## Bugs I found in other people's production code

- **Your AI agent's budget is fiction.** PraisonAI (9.3K stars) [#6433](https://github.com/MervinPraison/PraisonAI/pull/6433): every model newer than gpt-4o / Claude 3.x was billed at a $1/$3 default. A 100K-in / 5K-out gpt-5.5 call was booked at $0.115 instead of $0.65, so `max_budget=1.0` let about $3.42 through. Now priced at list rates, cache reads and writes included.
- **A price table in code is a bug on a timer.** microsoft/conductor [#645](https://github.com/microsoft/conductor/pull/645): 12 rows were wrong, mostly a 2/8 placeholder copied from model to model. The default model's output was billed at $8 per 1M instead of $12, and gpt-5.5 output was under-reported almost 4x. Fixed the rows, added my llm-prices as an optional dependency and a test that fails when a row drifts.
- **"Screened against sanctions" means "screened against the easy lists."** World Monitor (90.9K stars) [#10998](https://github.com/koala73/worldmonitor/pull/10998): screening covered OFAC, the CSL and Canada's SEMA list, and 153 of 190 UFLPA entities and 75 of 186 DoD 1260H rows returned no match at all. Added DoD 1260H, Section 889, the FCC Covered List and UFLPA as a sanctions source.
- **Most trading tools can't agree with themselves.** daily_stock_analysis (73.5K stars) [#2537](https://github.com/ZhuLinsen/daily_stock_analysis/pull/2537): the screener, alerts and report computed RSI three ways. On one 200-bar series the screener said 26.36 (oversold) and the report said 50.19 (neutral). Unified on one Wilder RSI from my fin-primitives, now in its requirements.txt.
- **A list that loads is not a list that works.** Moov Watchman [#1019](https://github.com/moov-io/watchman/pull/1019): the OpenSanctions Senzing loader ignored `NAME_ORG`, so all 207 DoD 1260H entities and 13 of 13 FCC Covered List entries loaded with empty names. The job went green and could not match a single one.
- **"Runs on embedded" usually means nobody tried.** AWS aws-lc-rs [#1292](https://github.com/aws/aws-lc-rs/pull/1292) + aws-lc [#3780](https://github.com/aws/aws-lc/pull/3780): aws-lc-sys did not build for QNX 8.0, which blocked rustls, hyper-rustls and reqwest, and aarch64 QNX failed to link (`OPENSSL_cpuid_setup`). Found by building the top 500 crates for QNX.
- **In hardware, a default value is a claim.** MAVLink rust-mavlink [#576](https://github.com/mavlink/rust-mavlink/pull/576): bitmask enums defaulted to their first flag, so a default `HEARTBEAT` serialized as `MAV_MODE_FLAG_SAFETY_ARMED`, and a serde test asserted the bug as expected output. Now default to no flags, with a regression test.
- **Your SBOM describes a build you didn't ship.** Eclipse KUKSA databroker [#244](https://github.com/eclipse-kuksa/kuksa-databroker/pull/244): the release was built with extra features and the SBOM without them, so it was missing 44 components, including axum, hyper and tungstenite.

## Tools that refuse to lie

A tool that guesses gives you a wrong number and a green check. These stop and say why.

- **[llm-budget](https://github.com/Mattbusel/llm-budget) 0.10** (Rust, released Nov 19): hard dollar caps for AI agents that fail closed. An unknown model, an unpriced cache token or a price older than 90 days refuses the call instead of guessing. `llm-budget audit` replays a call log and shows what a soft limit let through. [481 crates.io downloads](https://crates.io/crates/llm-budget); dependency of [agentai](https://crates.io/crates/agentai).
- **[llm-costcheck](https://github.com/Mattbusel/llm-prices/tree/main/costcheck) 0.1** (Rust, released Nov 19): reads your code, finds hard-coded model prices and $1/$3-style defaults, and fails CI with the error in percent and dollars.
- **[llm-prices](https://github.com/Mattbusel/llm-prices) 1.8**: 612 dated, source-cited LLM price rows for Python, Rust and TypeScript. [1,332 PyPI downloads in the last week](https://pypistats.org/packages/llm-prices), [417 on crates.io](https://crates.io/crates/llm-prices), 6 reverse dependencies on crates.io (tokensave among them); optional dependency of microsoft/conductor.
- **[fin-primitives](https://github.com/Mattbusel/fin-primitives) 4.0** (Rust with Python wheels, released Nov 19): 743 streaming indicators matched to TA-Lib, exact decimals. 4.0 is a breaking release because my own default ATR was a simple average, 5.4% above Wilder's on the test series: I had the bug I test other projects for, and fixed it. New `indicator-diff` shows where implementations disagree. [3,115 PyPI downloads in the last week](https://pypistats.org/packages/fin-primitives), [846 on crates.io](https://crates.io/crates/fin-primitives); runtime dependency of a 73.5K-star project.
- **[ownership-gap](https://github.com/Mattbusel/ownership-gap) 0.1** (Python, released Nov 19): a clean name screen is not a clean vendor. Puts a name-only OFAC/CSL screen beside the ownership rules and the five US lists the CSL leaves out, and exits 1 on any gap. Run over 366,981 vendors that 33 public buyers paid, it caught a city utility's $12.3M supplier that DoD names as a subsidiary of a 1260H company. Refuses to clear anyone against lists older than 7 days.
- **[us-restricted-parties](https://github.com/Mattbusel/us-restricted-parties)**: DoD 1260H, Section 889, FCC Covered List, UFLPA and BIOSECURE rebuilt daily as data; Watchman's docs list it. **Drones:** [remoteid](https://crates.io/crates/remoteid) (ASTM F3411 Remote ID, 788 downloads), [mavlink-tlog](https://crates.io/crates/mavlink-tlog), [misb](https://crates.io/crates/misb) (MISB KLV), [uas-cot](https://crates.io/crates/uas-cot).
- Totals: [84 crates, 15.8K crates.io downloads](https://crates.io/users/Mattbusel); [572 stars across 192 original GitHub repos](https://github.com/Mattbusel).
